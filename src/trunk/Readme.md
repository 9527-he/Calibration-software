# PDU校准工具

## 项目概述

这是一个基于 Go 语言开发的 PDU 校准工具，通过图形化界面实现 PDU 设备的自动化校准和测试。

## 功能说明

### 校准流程

1. **串口连接**

   - 标准电源串口：用于与标准电源通信
   - PDU串口：用于与待校准PDU通信
2. **6A负载测试**

   - 设置标准电源输出：220V, 6A
   - 读取标准电源数据：电压、电流、功率、功率因数
   - 将标准源数据写入PDU进行校准
   - 读取PDU数据并与标准源对比
   - 判断偏差是否在阈值范围内
3. **3A负载测试**

   - 设置标准电源输出：200V, 3A
   - 响应时间：5秒（已优化，原为18秒）
   - 读取标准电源数据
   - 读取PDU数据并与标准源对比
   - 判断偏差是否在阈值范围内
4. **清零功率**

   - 校准通过后，清零PDU的有功功率
5. **关闭标准电源**

   - 校准完成后，自动发送命令关闭标准电源输出

## 配置说明

### 阈值配置 (thresholds.yaml)

```yaml
VMaxDiff: 2.0    # 电压最大偏差 (V)
IMaxDiff: 0.1    # 电流最大偏差 (A)
PMaxDiff: 10.0   # 功率最大偏差 (W)
PfMaxDiff: 0.05  # 功率因数最大偏差
```

### 串口配置 (serial.yaml)

```yaml
SourceCOM: "COM1"  # 标准电源串口号
PDUCOM: "COM2"     # PDU串口号
```

### 调试配置 (debug.yaml)

```yaml
Modbus: 0      # Modbus调试开关 (0:关闭, 1:开启)
BreakPoint: 0  # 断点调试开关 (0:关闭, 1:开启)
```

## 开发说明

### 添加新的Modbus设备

1. 在 `devices/` 目录下创建新的设备驱动包
2. 实现设备的Open、Close、读写函数
3. 根据设备的Modbus寄存器地址定义更新通信协议

### 修改校准流程

编辑 `check/check.go` 中的 `Run()` 函数，可以添加新的测试步骤或修改现有逻辑。

### 修改GUI界面

- 导航栏：`gui/window/navigate.go`
- 信息栏：`gui/window/info.go`
- 表格显示：`gui/table/calibration.go`

## 注意事项

1. **数据格式转换**：注意浮点数与整数之间的转换精度
2. **串口参数**：确保通信的波特率、数据位等参数与设备匹配
3. **阈值设置**：根据实际精度要求调整 `thresholds.yaml` 中的阈值
